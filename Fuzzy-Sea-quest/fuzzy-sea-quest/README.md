# Animal Crossing Tokenomics Game

Welcome to the Animal Crossing Tokenomics Game! This project is a fun and interactive game inspired by the beloved Animal Crossing series, where players can engage in various activities while managing their in-game economy through tokenomics.

## Project Structure

The project is organized into several key directories and files:

- **src/**: Contains the main source code for the application.
  - **components/**: Contains React components for the game and UI.
    - **game/**: Components related to the game environment, including the village, characters, shops, and the island.
    - **ui/**: UI components such as inventory, wallet modal, and token display.
    - **common/**: Common components like header and footer.
  - **hooks/**: Custom hooks for managing game state, tokenomics, and wallet interactions.
  - **services/**: Functions for blockchain interactions, game logic, and token management.
  - **types/**: TypeScript types and interfaces for the game, tokens, and users.
  - **utils/**: Utility functions and constants used throughout the application.
  - **styles/**: CSS files for global and component-specific styles.
  - **App.tsx**: The main application component that sets up routing and renders the game interface.
  - **index.tsx**: The entry point of the application.

- **public/**: Contains static assets and the main HTML file.
  - **assets/**: Images and assets related to characters, items, and backgrounds.
  - **index.html**: The main HTML file that serves as the entry point for the application.

- **package.json**: Configuration file for npm, listing dependencies and scripts.

- **tsconfig.json**: TypeScript configuration file specifying compiler options.

## Getting Started

To get started with the Animal Crossing Tokenomics Game, follow these steps:

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd animal-crossing-tokenomics
   ```

3. Install the dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm start
   ```

5. Open your browser and navigate to `http://localhost:3000` to play the game!

## Features

- Explore a vibrant village filled with unique characters and shops.
- Manage your inventory and wallet through intuitive UI components.
- Engage in tokenomics by earning and spending tokens in the game.
- Interact with the blockchain for a decentralized gaming experience.
