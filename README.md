## 🛠️ Installation & Usage

### Quick Start
```bash
# Install the CLI
npm install -g fuzzy-octo

# Start the magic
fuzzy-octo "I need a function that does something with dates"
```

### VS Code Extension
```bash
# Install from marketplace
code --install-extension fullmeo.fuzzy-octo

# Or search "Fuzzy-Octo" in VS Code extensions
# Use Ctrl+Shift+F to summon the octopus 🐙
```

Visit [fuzzy-octo.scorescout.eu](https://fuzzy-octo.scorescout.eu) for the full experience!
